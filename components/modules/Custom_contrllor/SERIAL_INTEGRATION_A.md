# 完整轨迹缓存串口部署说明

本副本部署 `C:\Users\dong\Desktop\Custom_contrllor` 的完整轨迹缓存版本。
只改动 USART1 配置、串口任务入口和串口适配模块，不修改机械臂 PID、CAN、
电机映射、限位或夹爪控制算法。

## 数据路径

```text
USART1 DMA -> AA55解析 -> 完整轨迹缓存/校验/插值
            -> CC_handler六轴目标 -> 原HandTask（待电控授权接通）
反馈关节角 -> ROBOT_STATE -> USART1 DMA
```

## 当前控制代码造成的安全门

现有 `hand_task_set_output()` 没有 `HAND_MODE_CUSTOM_CTRL` 分支，模式刷新也没有
进入该模式。本适配器因此只有在控制层已经处于 `HAND_MODE_CUSTOM_CTRL` 时才
设置 READY；当前代码不会接受并执行视觉轨迹。

电控后续需要自行完成最小控制接线：通过本地人工授权进入该模式，并在该模式
调用已经存在的 `__hand_custom_ctrl()`。本提交没有替电控修改这部分。

夹爪 OPEN/CLOSE 函数当前为控制文件中的 `static` 私有函数，所以串口夹爪
命令会被拒绝；电控公开非阻塞请求接口后再连接。

## 真机前必须确认

- 六轴方向暂沿用旧输入 `{+1,-1,+1,-1,-1,+1}`，J2 零偏沿用旧换算。
- 位置软限位直接读取 HandTask 的 min/max。
- 串口层暂用 3 rad/s、10 rad/s² 作为轨迹校验上限，只是接入初值，电控必须
  按实车已验证参数确认后再允许自定义模式。
- 本工程没有明确的 ESTOP 查询接口，适配器没有伪造串口解除急停能力；电控
  必须继续保证本地急停独立生效。
